# Midnight Society — پلیر آکورد 🎵

پلیری که مثل پلیرهای معمولی نیست: **نوار آکورد** همراه آهنگ جلو می‌رود — هر خانه یک ضرب،
هر چهار خانه یک میزان — و صدایی که می‌شنوی همین لحظه ساخته می‌شود؛ هیچ فایل صوتی‌ای در پروژه نیست.

> **استک:** React 19 · Vite 8 · Tailwind 4 · Motion 14 · Appica UI (اسلایدر) · beUI
> **رابط:** فارسی و RTL، تم شبانه + روزانه، ریسپانسیو از ۳۲۰px تا دسکتاپ.

---

## اجرا

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # خروجی در dist/
npm run preview    # سرو کردن خروجی بیلد
```

نیازمند **Node 20+**.

## چطور کار می‌کند

**نوار آکورد (قلب پروژه)**
- هر خانه = یک ضرب، هر ۴ خانه = یک میزان (۴/۴)، جداکننده‌ی باریک بین میزان‌ها.
- نام آکورد فقط روی خانه‌ای نوشته می‌شود که آکورد عوض می‌شود؛ در ابتدای هر میزان، الگوی مضراب `D`/`U`.
- نشانگر پخش با همان motion value نوار حرکت می‌کند و ابتدای هر میزان، نوار یک میزان اسکرول می‌شود؛
  وسط اسکرول هم نشانگر دقیقاً روی ضرب واقعی است. روی هر خانه بزنی، از همان ضرب پخش می‌شود.

**سه تاگل مستقل** (دیاگرام آکوردها / متن آهنگ / میکسر)
- تاگل‌ها مستقل‌اند: هر ترکیبی بالا می‌ماند، از جمله حالت **همه‌خاموش**.
- دراور میکسر دقیقاً مثل دراورهای تمپو و گام **روی فوتر ترنسپورت** بالا می‌آید.

**دراورهای پایین**
- **تمپو** — کشیدن خط‌کش، پله‌های ±۱، پریست‌ها؛ روی پخش زنده اثر می‌گذارد.
- **گام** — ۱۲ نت؛ آکوردها، باس، پد و ملودی با هم ترنسپوز می‌شوند.
- **میکسر** — پنج ردیف استم (وکال/درامز/باس/پد/پیانو) به‌صورت آیکون + اسلایدر افقی،
  با یک ردیف `disabled`. اسلایدر، کامپوننت `Slider` از `@appica/ui-react` است؛
  حباب مقدار فقط **عدد** را نشان می‌دهد و وسط انگشتی می‌نشیند.
- هر سه با `BottomSheet` (کشیدن برای بستن، اسکرول‌لاک، Escape).

**ترنسپورت** — پخش/توقف ۶۴px، جست‌وجوی ±۵ ثانیه (⏪⏩ دو مثلث چسبیده، بدون دکمه‌ی ترک بعد/قبل)،
اسکرابر، و دو نمایشگر گوشه‌ای `BPM` / `KEY`.

### کیبورد

| کلید | کار |
|---|---|
| `Space` | پخش / توقف |
| `←` `→` | ۵ ثانیه عقب / جلو |
| `C` / `L` / `M` | دیاگرام آکوردها / متن آهنگ / میکسر |
| `T` / `K` | دراور تمپو / دراور گام |
| `Esc` | اول دراور، بعد پنل، بعد پلیر |

## صدا: واقعی، نه ماکاپ

`src/audio/engine.ts` یک موتور کوچک روی **Web Audio API** است:

| بخش | ساخت |
|---|---|
| پد | دو اسیلاتور saw با دیتون + فیلتر lowpass + پاکت بلند + ریورب |
| باس | triangle + ساب سین، فیلتر ۴۲۰Hz |
| گیتار/مضراب | پلاک saw کوتاه با فیلتر در حال بسته‌شدن، استرام ۱۲ms بین سیم‌ها |
| درامز | کیک سین‌سوییپ، اسنر (نویز + بدنه)، های‌هت/کرش (نویز فیلترشده) |
| ملودی | triangle + سین دو اوکتاو، ویبراتو ۵.۲Hz + ریورب و دیلی |
| فضا | Convolver با ایمپالس تولیدشده + دیلی ضرب‌دار |

- زمان‌بندی با **lookahead scheduler** (~۱۶ms) → درامز لرزش ندارد.
- تغییر تمپو یا گام وسط پخش → ادامه‌ی پخش از همان ضرب با تنظیمات جدید.
- سطح هر استم از `AnalyserNode` خودش خوانده می‌شود.

## دیزاین‌سیستم

رابط عمداً «بی‌رنگ» است؛ تنها اکسنت، تیل پروژه (`--accent`) و رنگ کاور ترک است.

| توکن | نقش |
|---|---|
| `--bg`, `--surface`, `--surface-2` | رنگ‌های پایه و سطح‌ها |
| `--fg`, `--fg-2`, `--fg-3` | متن اصلی / ثانویه / سوم |
| `--hairline`, `--hairline-2` | جداکننده‌های نیم‌پیکسلی |
| `--fill`, `--glass`, `--glass-tab` | پیل‌ها، چیپ‌ها و متریال شیشه‌ای |
| `--accent`, `--accent-soft` | تیل رابط |
| `--safe-t/b/l/r` | حاشیه‌های امن (notch و home bar) |

توکن‌های Tailwind شادکن (`--background`, `--card`, `--primary`, `--muted`, `--border`, …) در
`@theme inline` به همین توکن‌ها وصل شده‌اند؛ به همین دلیل `BottomSheet`، `Tabs` و `Slider`
بدون دست‌خوردن سورس، ظاهر همین سیستم را می‌گیرند.
